# Problem Solving Practice

This folder is for practicing the The Odin Project lesson on [Problem Solving](https://www.theodinproject.com/lessons/foundations-problem-solving).

### Process:
* Understand
* Plan (incl. pseudocode)
* Divide and Conquer
* Implement
* Debug

### Desired outcome per exercise:
* Problem description in my own words
* Input / Output
* Assumptions
* 2–4 test cases
* Rough plan / subproblems
* Pseudocode for the smallest next step
* Implementation
* Short debug log: What went wrong? Which assumption was tested?

### Rules:
* Do not search for complete solutions. Only research specific subproblems.
* An exercise is done when the listed outcome is complete and the test cases pass.
* Do not over-refactor or add edge cases beyond the stated assumptions.
